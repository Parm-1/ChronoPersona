# ChronoPersona Plan — Design v1.0

The **development content-integrity gate is passed**. Scientific execution is **externally blocked**. The program advances only when a gate has evidence, exact-head validation, and a recorded decision. A clean failed gate is progress.

## Resource envelope

- Default external spend: C$0.
- One training job at a time.
- No bulk corpus/model acquisition, paid license, requester-pays access, or cloud rental without explicit authorization.
- PEFT is engineering/reconnaissance only unless separately justified before results.
- No source-C compute before the A/B continuation gate passes.

## Milestone 0A — Novelty and design

**Status:** active until design-v1 PR merges green.

Complete when:

- ProgressGym is treated as the closest predecessor;
- novelty is prospective naturalistic A/B→C transport;
- A/B agreement is discovery-only;
- C is predesignated, sealed, decisive, and nonreplaceable after outcomes;
- ecological and composition-adjusted estimands are separate;
- prospective statistics and claim ladder are versioned;
- exact-head permanent checks pass.

Stop if equivalent prior work already performs common-weight naturalistic A/B discovery and frozen prospective held-out-source prediction.

## Milestone 0B — Models and compute

**Status:** externally blocked.

Audit exact artifacts for ProgressGym baselines, DatedGPT, PIT, ChronoGPT, TypewriterLM, OLMo 2, one cheap calibration model, and one alternate causal family.

Measure actual hardware, storage, runtime, load time, peak memory, complete-continuation throughput, tiny full-weight training throughput, checkpoint time, and recovery.

Pass when one common checkpoint and one fallback are legally accessible, immutable, capable, trainable, and supported by measured cost. Stop a path when capability, memory, artifact access, or authorized budget fails.

## Milestone 0C — Sources, eras, and roles

**Status:** externally blocked.

Audit at least four timestamp-native source candidates using bounded metadata and rights-qualified content samples. Measure timestamp/version integrity, rights, authorship, continuity, volume, composition, duplication, cross-posting, event concentration, direct exposure, and extraction cost.

Run masked cross-source era decodability. Freeze one era pair, A/B/C roles, and one feasibility backup using data only before behavioral inspection.

Pass when two discovery sources and one confirmatory source are viable, distinct, matchable, and legally auditable. One alternate source or era pair is allowed before behavior.

## Milestone 1 — Measurement

Expand factorial evidence-integration and procedural-policy item families. Create separate development and sealed confirmation partitions. Validate complete-continuation scoring, option/label/paraphrase/template invariance, tokenizer boundaries, capability, factual/register probes, malformed/refusal handling, and domain exposure.

Pass when reliability and meaningful-effect thresholds are frozen and confirmation can be run by one locked analysis pipeline.

## Milestone 2 — Synthetic identifiability

Run the frozen broad-update calibration across two independent synthetic training domains and a third unseen domain.

Pass only when explicit and indirect rules transfer, domain effect vectors agree, placebo/generic controls are near null, dose response follows plan, capability is retained, and branches replicate.

One predefined rescue is permitted. A second failure blocks naturalistic causal interpretation.

## Milestone 3 — Naturalistic A/B discovery

Run `2 eras × 2 discovery sources × 3 exploratory paired seeds` plus minimal controls. Estimate source vectors and frozen `g_AB` under the development partition.

Proceed to C only when measurement/calibration pass, A and B are estimable, agreement exceeds the frozen threshold, generic drift does not explain it, heterogeneity does not dominate, and no engineering defect remains.

Null or one-source outcomes stop before C spending unless one predefined calibration-supported scale/dose rescue applies.

## Milestone 4 — Sealed C confirmation

Choose confirmatory seeds by simulation. Complete opaque C branches, verify run completeness and hashes, execute frozen analysis, then unseal.

- C success: Level 4 CSTG across tested scope.
- C failure: reject CSTG; do not change source, era, items, estimator, threshold, or axis.

Then run the already-frozen composition adjustment.

## Milestone 5 — Common post-training

After C success, run neutral-buffer/order controls and identical SFT. Report endpoints and response to the common update; classify erased, masked, persistent, transformed, or path-dependent.

## Milestone 6 — Channel and mechanisms

Channel work runs only to explain positive CSTG, strong source-specific effects, or calibrated naturalistic nulls. Mechanisms begin only after C transport and require cross-source held-out prediction plus causal intervention.
