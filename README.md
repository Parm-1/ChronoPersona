# ChronoPersona

ChronoPersona is the internal codename for a falsification-oriented study of **Cross-Source Temporal Generalization (CSTG)** in language models.

## Central test

> Estimate an early-versus-late behavioral component from independent naturalistic discovery sources A and B, freeze it, and prospectively test whether it predicts the corresponding contrast from a predesignated sealed source C on unseen, date-neutral decisions.

A/B agreement is preliminary discovery evidence. Source C is decisive. If the frozen A/B component fails to predict C, the CSTG claim is rejected for the tested sources, model, dose, windows, and evaluation domains. C may not be replaced after results.

## Novelty boundary

ProgressGym already trained multi-source historical models on text spanning nine centuries, applied timeless instruction tuning, and used historical models in a value-oriented framework. Other work establishes historical cue generalization, naturalistic decade adaptation, ideological transfer, persistent midtraining priors, final-window path dependence, authored persona pretraining, persona directions, and point-in-time model infrastructure.

ChronoPersona therefore does not claim novelty from historical model construction, multi-source historical text, timeless post-training, moral-change measurement, broad transfer from one corpus, persistence, path dependence alone, or an “era vector.”

The remaining contribution is the prospective identification and transport of an unengineered period-indexed treatment across naturalistic source families.

## Critical path

1. Validate date-neutral measurement.
2. Pass Synthetic Identifiability Calibration using two disjoint synthetic training domains and a third unseen domain.
3. Run common-weight naturalistic A/B discovery branches.
4. Freeze the A/B temporal component, thresholds, estimator, exclusions, and confirmation evaluation.
5. Run sealed source-C confirmation.
6. Separately report ecological and composition-adjusted transport.
7. Apply common neutral continuation and identical SFT; measure erasure, masking, persistence, transformation, or path dependence.
8. Begin mechanisms only after prospective behavioral transport.

## Claim ladder

- Level 0: instrument or calibration failure.
- Level 1: knowledge/register only.
- Level 2: source-specific temporal effect.
- Level 3: preliminary A/B agreement.
- Level 4: prospective CSTG on C.
- Level 5: composition-adjusted persistence or path dependence.
- Level 6: shared causal temporal representation.

## Current status

The **development content-integrity gate is passed**. The bounded local
snapshot, tokenizer, training-resume, and registry-scorer engineering paths are
Target Verified; measurement development remains active. Scientific execution
is **externally blocked**.

No evidence-bearing scientific model training or real-source qualification has
occurred. One local engineering-only tiny-LoRA control failed before backward;
its sole attention-policy rescue passed a five-step control and planned
interruption/resume gate with exact final semantic state equality. This is
trainer/checkpoint engineering evidence only. The exact Pythia scorer also
reproduced byte-identical scores across two fresh invocations, but four of
twelve development items changed direction across paraphrases. The scorer path
passed; measurement reliability is not established. Source roles, era windows,
causal checkpoint, dose, confirmation evaluation, meaningful-effect threshold, and
prospective estimator remain unfrozen.

External blockers include:

- bounded rights-qualified, historically versioned real-source samples;
- source continuity, composition, overlap, and exposure measurements;
- delivery and exact-head CI for the predeclared development-v1 scorer,
  followed by one bounded coherence result and reliability decision;
- sustained training and broad-update cost evidence for any later branch plan;
- expanded development and sealed confirmation evaluation partitions.

Default external-compute authorization remains **C$0**.
