# D-028 — Make Prospective Source-C Transport the Central CSTG Claim

**Date:** 2026-08-18  
**Status:** accepted  
**Reversibility:** scientific framing is reversible only if new prior art or feasibility evidence changes the identification problem

## Question

What remains novel after ProgressGym and the final literature pass?

## Alternatives

1. Historical model construction.
2. Multi-source historical continued pretraining plus timeless instruction tuning.
3. Measuring moral or social change in historical models.
4. Showing that one historical corpus changes unrelated behavior.
5. A/B cross-source agreement without prospective confirmation.
6. Prospective transport of a frozen A/B component to predesignated sealed C.

## Evidence

ProgressGym already performs multi-source historical model construction across nine centuries, applies timeless instruction tuning, and uses the models in a historical value-oriented framework. Other work establishes broad historical generalization, naturalistic temporal adaptation, ideological transfer, pretraining priors, final-window path dependence, authored personas, persona directions, and point-in-time model infrastructure.

ProgressGym explicitly identifies temporal source-composition changes and uncertain historical-value injection as limitations. A/B agreement alone does not resolve those problems because the discovery process can adapt to A and B.

## Decision

Select alternative 6.

CSTG is defined as a shared early-versus-late component estimated from independent discovery sources A and B that prospectively predicts the corresponding contrast in a predesignated sealed source C on unseen date-neutral decisions.

- A/B agreement is Level 3 preliminary evidence.
- C success supports Level 4 CSTG across tested scope.
- C failure rejects CSTG for that scope.
- C may not be replaced after outcomes.
- Ecological and composition-adjusted CSTG are separate estimands.
- “Temporal prior” requires adjusted transport plus capability, factual, register, continuation, and common post-training/path controls.
- Mechanisms begin only after C transports.

## Consequences

- The public checkpoint audit becomes optional and nonblocking.
- ProgressGym is a top-tier novelty threat and baseline, not a passing citation.
- Source roles and one feasibility backup must be fixed before behavioral inspection.
- Confirmation evaluation, estimator, thresholds, directions, exclusions, and failure rules must be frozen before C unsealing.
- No source/era/item/estimator rescue follows C failure.
- A source-specific, composition-mediated, calibrated null, channel-dependent, or post-training-erased result can still be scientifically successful at a lower claim level.

## Current execution consequence

Merge design v1.0 only on an exact green head, then stop until bounded real-source evidence and measured local model/compute evidence exist.
